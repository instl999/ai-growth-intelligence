# GitHub selection policy

Retain a repository only when it meets the shared operator interest profile and is likely to create practical value. Read `operator-interest-profile.md` first.

- Start from the GitHub repository page, release notes, maintainer documentation, and relevant official project sites. Treat stars, forks, and social posts as discovery signals, not proof of quality.
- Apply the shared profile with additional GitHub emphasis: inspect implementation quality, active maintenance, setup effort, license, security posture, and code/deployment reusability.
- Give additional weight to a recent meaningful release, clear setup documentation, active maintenance, an understandable use case, and a license that permits the intended trial.
- Check whether the repository is a copy, abandoned, deceptive, excessively risky, or primarily promotional. Do not recommend it solely because it is trending.
- Include: what it does, why it is worth attention now, likely fit and limitations, repository URL, official homepage when available, license or pricing implications when relevant, and one concrete first action.
- Evaluate `worldwonderer/novel-to-game` by the same criteria as every other repository. It is not an interest profile, standing endorsement, or mandatory search term.
