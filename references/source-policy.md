# Source policy

- Search public domestic and international sources through the host client's web tools, following `host-search-protocol.md`.
- Require at least one official or first-party source for every publishable item.
- Require two independent sources for material claims.
- Prefer immediate efficiency or income impact and significant future-trend impact.
- Exclude marketing copy, course promotion, duplicate coverage, clickbait, and unsupported claims.
- Treat a search-result snippet as a lead, not as a source. Open the underlying page before verification.
- Apply `operator-interest-profile.md` as an additional relevance filter for AI information. It supplements, and never replaces, the baseline verification, value, safety, and anti-promotion requirements.
- For Skill discovery, independently scan ClawHub, SkillHub, skills.sh, SkillsMP, and GitHub repositories containing installable Skills, then apply `skill-selection-policy.md`. Treat directory/index pages as evidence only for platform metadata; verify capability claims with the creator's repository or official documentation.
