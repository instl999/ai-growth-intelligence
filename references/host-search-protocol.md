# Host search protocol

1. Prefer the host client's public web-search and browsing capabilities.
2. Search broad Chinese and international sources; open underlying pages before treating a result as evidence.
3. Run separate Skill discovery searches for `clawhub.ai`, `skillhub.cn`, `skills.sh`, `skillsmp.com`, and GitHub repositories containing `SKILL.md` or explicit Agent Skill directories. Open individual listings or repositories and trace retained candidates to creator repositories or official documentation.
4. Require official or first-party evidence for every retained item, and two independent sources for material claims.
5. Treat Skill-directory listings, rankings, downloads, classifications, indexed counts, update timestamps, and badges as discovery or platform metadata, not proof of functionality, safety, maintenance, or compatibility.
6. If only search is available, show results as unverified internal candidates. Do not create a publishable article item.
7. If no web search is available but the client can discover installable Skills, find public Skills that provide web search and browsing. Show candidates and request explicit approval before installation.
